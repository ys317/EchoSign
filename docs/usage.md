# 使用指南

## 课堂与账号

直播网址是选填的快捷入口。直接在浏览器打开并播放课程即可，留空不影响监控。EchoSign 识别默认扬声器或耳机播放的声音；切换输出设备后，请停止并重新启动监控。

使用签到辅助时，在「课堂」页填写本人的杭电账号，点击「登录 / 刷新」。验证码等验证由本人完成。

签到位置也在「课堂」页。点击「获取当前位置」可通过 Windows 系统定位填入经纬度，显示的误差范围由系统提供；核对后点击「保存」，也可以手动填写。定位需要在 Windows「设置 → 隐私和安全性 → 位置」（Windows 10 为「设置 → 隐私 → 位置」）中开启位置服务并允许桌面应用访问位置。未开启、权限不足或定位超时时，软件会显示原因，保留原有坐标。

初始默认值为纬度 `30.314732`、经度 `120.343727`，这不是自动测得的当前位置。已有个人设置仍会保留。签到使用已保存的经纬度，请在启动监控前核对；获取位置只在点击按钮时进行，返回的是经纬度，不含街道门牌地址。

只需转写与提醒时，关闭「自动签到」，可跳过账号登录。

## 转写与签到码

点击「启动监控」后，软件先初始化本地模型，再开始接收电脑播放的声音。右侧显示最近一句转写，下方活动记录显示已完成的转写和操作记录。

点击「停止监控」会清空待处理的签到任务，并停止正在运行的签到浏览器；清理完成后可再次启动监控。监控期间关闭窗口也会等待清理完成。已提交到平台的签到请求无法撤回，请以平台记录为准。

确认后的四位签到码会显示在卡片上，点击「复制」即可粘贴到课堂页面。同一堂课可以识别多个不同的签到码。重新启动监控会清除上次的签到码，避免误用；「清空」只清理活动记录的显示，保留当前签到码和计时。

默认支持提前提码：同一码在连续识别中保持稳定，四位数字后已经出现后续话语，或者已经完整重复读出两遍，就可以在整句话结束前显示、通知和签到。刚出现四位数字时还可能继续增长为长数字串，因此先等候确认；不满足提前确认条件时，仍使用整句完成后的结果。

启用「自动签到」后，听到签到提示或候选码时会提前打开签到页，确认码后才输入并提交。同一次监控复用浏览器，每轮结束后准备空白键盘，供下一轮签到使用。页面可用就继续操作，实际等待仍受登录状态和学校网络影响。

## 识别与通知

- 「识别」页支持每行一个关键词，也支持以 `re:` 开头的正则表达式。语义辅助识别默认关闭，可按需要开启；它在本机运行，发行包已包含模型。
- ASR 热词默认关闭。在 `config.yaml` 中设置 `asr.hotwords` 可试用；热词也可能改错数字或增加误报，建议先用自己的课堂录音核对。清空该列表即可关闭。
- 企业微信 Webhook 可留空。填写后可点击「测试推送」，收到的标题与正文均标识 EchoSign。
- 「保存」或 `Ctrl+S` 保存设置。运行期间修改识别、通知等设置，需要重新启动监控后生效。

## 升级

关闭旧版，将新版解压到新目录。需要保留设置时，复制旧目录中的 `config.yaml`、`secrets_local.json`、`session_local.json` 和 `browser_profile/`，然后打开新版。不要覆盖新版的程序、运行库或模型文件。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 无法启动，或提示文件缺失 | 重新完整解压 Windows ZIP；不要从压缩包内运行，也不要只复制 exe。 |
| 没有转写 | 确认课程有声音，并从当前默认输出设备播放；切换设备后重启监控。 |
| 登录过期或签到结果未知 | 重新登录，并在「上课啦」核对结果。 |
| 无法保存 | 将软件放到当前用户可写的目录，例如 `D:\Apps\EchoSign`。 |

## 本地数据

配置、账号、登录态和命中记录保存在软件目录中。`secrets_local.json` 明文存储密码，`session_local.json` 与 `browser_profile/` 包含登录凭据，请勿公开分享。

转写与语义识别在本机完成；登录、签到和企业微信通知需要联网。界面的「清空」只清理显示，不删除磁盘记录。卸载时关闭软件并删除整个目录即可。
