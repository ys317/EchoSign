# 使用指南

## 课堂与账号

打开软件后，从侧栏账号菜单进入「设置」，输入本人学号和密码，点击「登录并读取课程」。软件自动填写登录表单，验证码等验证仍由本人完成。登录成功后选择课程，点击「开始监控」或「预约直播」即可，账号、课程和设置会自动保存。

「设置」中可调整两种声音来源：

- **后台音频**（新配置默认）：选择课程后自动启用。当前课程点击「开始监控」，未来课程点击「预约直播」，软件直接接收直播声音，无需保持网页播放，也不会从扬声器播放课程声音。
- **电脑声音**：在设置中关闭「后台音频」，再在浏览器打开并播放课程。直播网址只是选填的快捷入口，留空不影响监控。软件识别默认扬声器或耳机播放的声音；切换输出设备后，请停止并重新启动监控。升级时保留已有声音来源设置，选择直播课程后会自动切回后台音频。

已有直播登录时，打开软件会自动读取课程，也可以点击「刷新课程」。刷新只更新列表，需本人选择课程；不会自动选中另一堂课。手动输入可在「设置」中通过「手动填写网址」展开。列表为空或读取失败时，页面显示原因并保留已有手动地址，登录过期请重新登录。

课程列表保留今天与明天的课程；明天的课程会显示「明日」和开始时间。底部只保留一个操作按钮：未到开课时间显示「预约直播」，到点自动变为「开始监控」，无需重新选择。预约后按钮显示「取消预约」，并显示倒计时，到点自动启动；正在监控时显示「停止监控」。自动启动留出约 2 秒缓冲。预约只保存课程编号、名称、起止时间、教师教室等课程信息，不保存账号、密码或 Cookie；重启软件后会恢复未到期的预约。修改账号或直播地址、关闭「后台音频」、选择其他课程会取消原预约。

到点后软件沿用正常的监控启动流程：开启后台音频、初始化识别，并在「自动签到」启用时提前准备签到页。预约需要保持软件运行；系统睡眠后若课程仍在进行，唤醒后会尝试启动，已结束则自动忽略。若老师尚未开播、直播登录失效或平台接口变化，会显示原有监控错误，需要处理后手动启动。

后台音频适合只需要转写和提醒、希望减少网页和视频占用的情况。目前支持杭电平台的 HTTP(S)-FLV 直播；直播尚未开始、已经结束或格式不支持时，会显示原因。此时可关闭「后台音频」，继续使用电脑声音模式。短暂断流会自动重连，持续失败约两分钟后停止并提示；恢复稳定接收后，下一次断流可重新尝试。网络补发或电脑短暂繁忙造成的音频积压会先缓冲再追赶；积压超过约 10 秒时跳过积压部分并在记录中提示，监控继续进行。更换直播链接后需要重新启动监控。直播源同时包含画面时，网络流量未必明显下降。

重连期间界面显示「正在重连」，收到声音后恢复「监控中」。登录过期、无观看权限、证书或组件问题会直接提示处理；不会自动打开登录窗口。点击「停止监控」可取消重连等待。本版只重连当前选择的这一节，不自动切换下一节；后续设计见[分节衔接方案](live-continuation-plan.md)。

需要更换账号时，从侧栏账号菜单打开账号设置，修改账号密码，再点击「登录并读取课程」。本次登录使用独立窗口，不复用旧账号；账号更改会清空课程选择并取消预约，登录未完成时无法用旧会话刷新或启动直播。高级用户仍可在设置中点击「单独登录直播账号」，手动完成独立的直播登录。外部浏览器里的账号切换不会自动同步到软件。

签到辅助共用设置中填写的账号，启用「自动签到」后，启动监控会自动登录并准备签到页；若需提前验证，可在「设置」点击「重新登录签到」。签到会话按账号分别保存，升级后的首次使用可能需要重新验证。

签到位置在「设置」页。点击「获取当前位置」可通过 Windows 系统定位填入经纬度，显示的误差范围由系统提供；核对后点击「保存」，也可以手动填写。定位需要在 Windows「设置 → 隐私和安全性 → 位置」（Windows 10 为「设置 → 隐私 → 位置」）中开启位置服务并允许桌面应用访问位置。未开启、权限不足或定位超时时，软件会显示原因，保留原有坐标。

初始默认值为纬度 `30.314732`、经度 `120.343727`，这不是自动测得的当前位置。已有个人设置仍会保留。签到使用已保存的经纬度，请在启动监控前核对；获取位置只在点击按钮时进行，返回的是经纬度，不含街道门牌地址。

只需转写与提醒时，在设置中关闭「自动签到」，可跳过签到登录。后台音频仍需要取得课程的观看权限；直播登录与签到登录分别保存，互不覆盖。

## 转写与签到码

点击「开始监控」后，软件先初始化本地模型，再开始接收所选来源的声音。后台音频模式会先确认直播可用，收到声音后才显示正在监控。首页采用左右布局，左侧填写账号和选择课程，右侧显示最近一句转写、签到码与运行状态；详细活动记录默认折叠，点击「活动记录」展开。折叠不影响记录和识别。

点击「停止监控」会清空待处理的签到任务，并停止正在运行的签到浏览器；清理完成后可再次启动监控。监控期间关闭窗口也会等待清理完成。已提交到平台的签到请求无法撤回，请以平台记录为准。

确认后的四位签到码会显示在卡片上，点击「复制」即可粘贴到课堂页面。同一堂课可以识别多个不同的签到码。重新启动监控会清除上次的签到码，避免误用；「清空」只清理活动记录的显示，保留当前签到码和计时。

默认支持提前提码：同一码在连续识别中保持稳定，四位数字后已经出现后续话语，或者已经完整重复读出两遍，就可以在整句话结束前显示、通知和签到。刚出现四位数字时还可能继续增长为长数字串，因此先等候确认；不满足提前确认条件时，仍使用整句完成后的结果。

启用「自动签到」后，启动监控时就会在后台任务中打开签到浏览器并准备签到页，不必等待口播提示；页面准备与音频初始化同时进行，确认码后才输入并提交。同一次监控复用浏览器，每轮结束后准备空白键盘，供下一轮签到使用。页面准备失败不阻塞转写，确认码后会再尝试打开。关闭自动签到时不会预开页面；若旧配置显式设置了 `auto_sign.prewarm_browser: false`，改为 `true` 可启用启动时预开。实际等待仍受登录状态和学校网络影响。

## 识别与通知

- 「设置」页的识别设置支持每行一个关键词，也支持以 `re:` 开头的正则表达式。语义辅助识别默认关闭，可按需要开启；它在本机运行，发行包已包含模型。
- ASR 热词默认关闭。在 `config.yaml` 中设置 `asr.hotwords` 可试用；热词也可能改错数字或增加误报，建议先用自己的课堂录音核对。清空该列表即可关闭。
- 企业微信 Webhook 可留空。填写后可点击「测试推送」，收到的标题与正文均标识 HDUSign。
- 「保存」或 `Ctrl+S` 保存设置。运行期间修改识别、通知等设置，需要重新启动监控后生效。

## 升级

关闭旧版，将新版解压到新目录。需要保留设置时，复制旧目录中的 `config.yaml`、`secrets_local.json`、`session_local.json` 和 `browser_profile/`；使用过后台音频时，也可复制 `live_session.json` 和 `live_profile/`，然后打开新版。不要覆盖新版的程序、运行库或模型文件。旧配置如仍使用 4 线程，可将 `asr.num_threads` 改为 `1`，重启应用后生效。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 无法启动，或提示文件缺失 | 重新完整解压 Windows ZIP；不要从压缩包内运行，也不要只复制 exe。 |
| 电脑声音模式没有转写 | 确认课程有声音，并从当前默认输出设备播放；切换设备后重启监控。 |
| 后台音频没有转写 | 确认课程正在直播，点击「登录并读取课程」刷新登录；查看活动记录中的直播状态或格式提示。 |
| 网页播放卡顿、占用高 | 使用「后台音频」，登录后关闭播放网页；不支持的直播格式仍需使用电脑声音模式。 |
| 识别程序 CPU 占用高 | 将 `config.yaml` 中的 `asr.num_threads` 设为 `1`，并重启应用。新配置默认使用单线程，保留原识别模型与 0.25 秒音频块。 |
| 登录过期或签到结果未知 | 重新登录，并在「上课啦」核对结果。 |
| 无法保存 | 将软件放到当前用户可写的目录，例如 `D:\Apps\HDUSign`。 |

## 本地数据

配置、账号、登录态和命中记录保存在软件目录中。`secrets_local.json` 明文存储密码，`session_local.json`、`browser_profile/`、`live_session.json` 与 `live_profile/` 包含登录凭据，请勿公开分享。

转写与语义识别在本机完成；直播取流、登录、签到和企业微信通知需要联网。后台音频只读取直播播放信息，不自动切换课堂。界面的「清空」只清理显示，不删除磁盘记录。卸载时关闭软件并删除整个目录即可。

## 界面与响应

v1.9 桌面使用 Qt Quick。右上角可聚焦正文、展开活动记录或切换主题；设置保存使用 `Ctrl+S`，深浅主题切换使用 `Ctrl+Shift+L`。转写可以拖选复制，签到码保留前导零。活动记录仅展示最近 20 条签到事件及 1500 条日志，磁盘记录不受显示条数限制。

遇到图形驱动兼容问题时，可先更新驱动。源码诊断可设置 `QT_QUICK_BACKEND=software` 后启动；软件渲染主要用于兼容性排查，性能可能下降。退出时软件会请求后台任务停止，并等待当前网络调用结束；课程预约需要软件持续运行。
