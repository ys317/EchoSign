# EchoSign v1.7

- 新增「后台音频」：在「课堂」页填写杭电直播链接，完成「登录直播」后即可直接识别直播声音，无需网页持续播放。
- 实时语音识别默认改为单线程。保留原模型与 0.25 秒输入节拍，减少实时等待期间的 CPU 开销。
- 直播与播放信息接口短暂中断时逐步重连，连续故障恢复窗口为两分钟；恢复稳定接收后重置重试次数。登录失效、无权限、直播结束等情况明确停止并提示。
- 重连期间界面显示「正在重连」，收到声音后恢复监控状态。断流时丢弃未确认的识别片段，避免把断开的数字拼成签到码；停止时取消等待并回收音频进程。
- 修复直播音频频繁出现「处理速度不足，缓冲已满」并在两分钟后停止的问题：直播输入不再限速读取，音频缓冲从 2 秒扩大到 10 秒以吸收网络补发和识别器短暂停顿；缓冲仍然填满时只跳过积压、重置识别器并继续，不再断开重连，也不计入故障窗口。
- 直播登录与签到登录分别保存，可通过「换账号」手动选择直播账号。后台音频处理不弹命令行窗口，便携包内置音频组件，无需额外安装。
- 改善「课堂 / 识别 / 通知」切换的响应，减少页签重绘，并避免缩放后隐藏页重新出现。日志积压时分批更新，保留完整记录与最新转写，让停止和切页按钮及时响应。
- 内置精简音频组件，使用 Windows 证书信任库验证 HTTPS；同一发布页提供匹配的完整 FFmpeg 源码与构建脚本。
- 保留 v1.6 的签到位置获取、课堂页位置设置、EchoSign 测试推送名称与隐藏命令行窗口改进。

当前后台音频仅适配杭电 HTTP(S)-FLV 直播，不自动切换到下一节课。平台返回其他格式时，请使用原有电脑声音模式。

分节衔接本次只给出[方案](https://github.com/ys317/EchoSign/blob/v1.7/docs/live-continuation-plan.md)，已核实同一教学班的两节关联及时间，第三节仍待验证。

下载 `EchoSign-v1.7-win64.zip` 并完整解压后运行 `EchoSign.exe`。音频组件对应源码为同页的 `ffmpeg-8.1.2-echosign-audio-source.tar.xz`，校验值见 `SHA256SUMS.txt`。

本机对照测试中，1/2/4 线程的 ASR 平均整机 CPU 占用约为 1.90%/23.17%/62.72%，单线程处理仍满足实时节拍。另已验证正在进行的杭电 HTTPS-FLV 直播：登录窗口关闭后持续取声并产生转写，取声与识别合计平均占用约 3%，停止后正常回收。该短时验证不包含 GUI、签到浏览器或整节课的长时间运行。
