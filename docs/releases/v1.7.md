# EchoSign v1.7

- **自动读取直播课程**：在「课堂」页登录杭电课堂后自动加载当前直播课程。选择课程即可填入地址并开启后台音频，不用每节课重新复制链接。已有登录时打开软件自动刷新，也可手动刷新、换账号或填写网址。
- **启动监控即准备签到页**：启用自动签到后，监控启动时就打开签到浏览器，与音频初始化同时进行；确认签到码后才输入并提交。同次监控复用页面，停止后回收浏览器。
- **精简设置界面**：分为「课堂 / 签到 / 更多」。课堂保留选课、声音来源和自动签到，账号与定位集中到签到页，识别与通知归入更多，手动网址默认收起。
- **后台直播音频**：直接接收杭电 HTTP(S)-FLV 直播声音，无需保持网页播放。默认单线程识别，减少 CPU 占用；临时网络故障自动重连，音频积压时追赶或跳过并提示。
- 保留深浅主题、关键词与语义辅助、签到码复制、企业微信通知和 Windows 定位。改善切页、缩放和日志积压时的响应。

下载 **EchoSign-v1.7-win64.zip**，完整解压后运行 `EchoSign.exe`。便携包包含浏览器、识别模型及音频组件，无需安装 Python。匹配的完整 FFmpeg 源码与构建脚本见同页 `ffmpeg-8.1.2-echosign-audio-source.tar.xz`，校验值见 `SHA256SUMS.txt`。

升级时可从旧版复制个人配置与登录文件；不要覆盖新版运行库和模型。若旧配置显式关闭 `auto_sign.prewarm_browser`，改为 `true` 即可启用启动时预开签到页。

课程列表依赖本人直播登录与学校平台可用性。本版不自动切换下一节课，选择另一节后需重新启动监控。登录过期请重新登录；不支持的直播格式仍可使用电脑声音模式。
