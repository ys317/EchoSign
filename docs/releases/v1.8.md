# EchoSign v1.8

- **预约明天的直播课**：登录直播后读取平台首页的直播数据，并保留今天和明天的课程；明天的课程会标出开始时间。选择后点击「预约监控」，软件按课程接口返回的开始时间显示倒计时，到点自动启动监控。
- **预约可跨重启保留**：预约只保存课程编号、名称、起止时间和教师教室等信息，不保存账号、密码或 Cookie。关闭再打开软件后，未到期的预约会自动恢复；手动改地址、关闭后台音频或换选课程会取消预约。
- **沿用完整监控流程**：到点后仍走原有启动路径，自动开启后台音频、初始化本地识别；启用自动签到时也会提前打开签到页。系统睡眠后唤醒，若课程仍在进行会继续尝试启动。

下载 **EchoSign-v1.8-win64.zip**，完整解压后运行 `EchoSign.exe`。便携包包含浏览器、识别模型及音频组件，无需安装 Python。匹配的完整 FFmpeg 源码与构建脚本见同页 `ffmpeg-8.1.2-echosign-audio-source.tar.xz`，校验值见 `SHA256SUMS.txt`。

升级时可从旧版复制个人配置与登录文件；不要覆盖新版运行库和模型。课程读取与平台首页一致使用 `liveDay=0`，再按课程开始时间在本地筛选今天与明天；仍依赖本人直播登录、老师按时开播和学校平台可用性。登录过期请重新登录，不支持的直播格式可继续使用电脑声音模式。
