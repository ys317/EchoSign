# EchoSign v1.6

本次更新重点缩短口播签到码的确认和网页操作等待，同时改进错误提交防护与停止监控的清理行为。

## 更快提码与签到

- 支持有条件的提前提码：同一码在多次实际识别中稳定至少 0.4 秒，且数字后已有后续话语，或已完整重复报码时，可以不等整句话结束就确认。
- 听到签到提示或候选码后，提前准备「上课啦」签到页；确认码后才输入并提交。
- 同一次监控复用签到浏览器，每轮结束后准备空白键盘，支持一堂课多次签到。
- 页面与按钮可用即继续操作，减少进入签到页、逐位输入和检测登录状态时的固定等待。实际耗时仍取决于登录状态、电脑和学校网络。

## 可靠性改进

- 刚出现的四位数字仍可能增长或改字，未满足确认条件时继续等待；加强对混合数字、长数字和重复报码的处理。
- 改进连续音频采集、重采样和录音结尾处理，减少音频断续与尾部识别不完整的问题。
- 停止监控会取消等待中的签到任务并关闭正在处理任务的浏览器，清理完成后可以重新启动。
- 签到结果严格匹配本次码和平台响应；无法确认结果时提示核对，不自动重试已经发出的请求。
- 修复 Windows 下连续签到时请求文件偶发被占用的问题；前后两次签到的输入和结果独立处理。
- 修复无控制台或重定向日志的 exe 在回放录音时因转写输出、字符编码问题而中断；输出统一使用 UTF-8。
- 改进监控重启时的旧码清理、界面状态恢复和异常提示。

## 默认配置与升级

- 直播网址标为选填，直接在浏览器播放课程也可监控。
- 签到位置移至「课堂」页，增加「获取当前位置」按钮，使用 Windows 系统定位；默认纬度 `30.314732`、经度 `120.343727`，已有个人设置保持不变。
- 测试推送的标题和正文统一使用 EchoSign 名称。
- 后台辅助命令隐藏命令行窗口，保留登录及课堂浏览器的正常显示。

新安装默认开启提前提码和签到页预备，关闭 ASR 热词与语义辅助识别；需要时仍可自行开启实验选项。沿用旧 `config.yaml` 会保留原有热词和语义设置，缺少的提前提码、页面预备选项使用新版本默认值。

关闭旧版，将 **`EchoSign-v1.6-win64.zip`** 完整解压到新目录，双击 **`EchoSign.exe`** 运行。支持 Windows 10 / 11 x64，内置运行环境、浏览器、语音及语义模型，无需安装 Python。

需要保留个人设置时，从旧目录复制 `config.yaml`、`secrets_local.json`、`session_local.json` 和 `browser_profile/`。请保留新版的 `EchoSign.exe`、`_internal/` 和 `models/`；使用前检查设置，登录过期时重新登录。

发行文件同时提供 `SHA256SUMS.txt`，用于核对 ZIP 文件是否完整。完整使用与升级说明见包内 `docs/usage.md`。
