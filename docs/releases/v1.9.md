# HDUSign v1.9

首页收敛为「账号密码 → 登录并读取课程 → 一个操作按钮」。未到开课时间显示「预约直播」，到点自动切换为「开始监控」；预约后显示「取消预约」和倒计时，运行时显示「停止监控」。重启后继续恢复未到期的预约。

- 侧栏账号菜单可打开账号设置，直播登录自动填写当前输入的账号，成功后读取今明课程；验证码仍由本人完成。
- 采用 Notion 风格双栏布局：240px 侧栏可折叠为 56px，正文居中限宽并支持整页滚动，窄窗口也能完整查看内容。
- 移除侧栏品牌文字，新增 40px 面包屑栏「HDUSign / 📡 课堂监控」，提供聚焦、活动记录和更多选项。
- 停止监控与取消预约使用透明底、柔和红字、细红边框的次级危险按钮，悬停时显示浅红背景。
- 标题下方使用两行页面属性：状态标签与等宽时长；监控中显示浅绿色标签，预约时显示距离开课时间。
- 实时转写改为 17px、1.6 倍行高的自适应引用块，带 3px 竖线与 14px 左侧内边距；正文最大宽度为 840px。签到码使用 24px 等宽粗体白色数字牌，以细边框区分层次。
- 统一 Notion 色板；使用系统无衬线字体，Windows 中文优先使用微软雅黑 UI。侧栏使用中性灰选中态，状态使用浅绿色，危险操作使用柔和红色。卡片不使用阴影，卡片与菜单圆角为 3–5px。
- 签到码区域浅色模式使用淡黄色，深色模式使用中性炭灰底与细边框，避免暗黄色大色块。
- 属性名称带淡灰图标并固定列宽，数值垂直对齐；课程信息分行排版，长文字使用 Qt 原生省略号，并可悬停查看完整信息。
- 活动记录改为可展开的三角折叠列表，显示本次会话最近 20 条签到事件和详细日志。
- 桌面渲染迁移到 PySide6 / Qt Quick，保留 Python 识别、登录、预约和签到逻辑；Windows 默认使用 Qt 选择的硬件渲染后端。
- 状态按字段通知，转写批量合并；活动记录按需创建，滚动时复用列表项，详细日志限制为 1500 条。无需每次更新都重新绘制整页。
- 系统字体统一度量，标题使用粗体，签到码使用 Cascadia Mono / Consolas 等宽字体，线性图标按 DPI 缓存。
- 设置校验失败时自动滚动到对应字段；转写和计时更新不打断输入光标。停止与关闭等待后台任务通过取消事件收尾。
- 项目统一更名为 HDUSign，Python 入口改为 `python -m hdusign`，新构建程序为 `HDUSign.exe`。既有发布归档与源码校验记录保留原文件名。
- 新配置默认接收直播音频，选择课程即可使用，无需手动复制网址或选择音频来源。已有声音来源设置继续保留。
- 签到、位置、识别、通知及手动网址统一移到「设置」。高级用户仍可单独登录直播账号。
- 更换账号会清除旧课程选择和预约；登录失败时不使用旧账号继续刷新或监控。签到浏览器按账号分别保存会话，首次使用可能需要再次验证。

预约需要保持软件运行，不能在关机时启动。登录、监控和预约自动保存设置；界面与登录流程的回归测试使用模拟数据，不连接学校服务。
