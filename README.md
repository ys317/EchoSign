# EchoSign

[![Release](https://img.shields.io/github/v/release/ys317/EchoSign)](https://github.com/ys317/EchoSign/releases/latest)
![Windows](https://img.shields.io/badge/Windows-10%20%2F%2011%20x64-0078D4)
[![MIT License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

面向**杭州电子科技大学「上课啦」**的 Windows 课堂辅助工具。将电脑播放的课堂声音实时转为文字，识别签到提示与四位口播签到码，并提供可选的企业微信通知和浏览器签到辅助。

[下载 Windows 版](https://github.com/ys317/EchoSign/releases/latest) · [快速开始](#快速开始) · [使用指南](docs/usage.md) · [问题反馈](https://github.com/ys317/EchoSign/issues)

## 功能特点

- **本地语音识别**：采集电脑播放的声音，在本机完成流式中文转写，无需调用云端语音服务。
- **签到提示识别**：支持关键词、正则表达式、组合词和语义匹配，可按课堂习惯调整规则。
- **口播签到码提取**：识别四位数字及「一二三四」「幺二三四」等中文读法，支持一键复制。
- **可选通知与辅助**：支持企业微信机器人提醒，以及「上课啦」的登录与签到操作。
- **深浅主题**：实时转写与活动记录分区显示，主题切换后自动记住选择。
- **解压即用**：Windows 发行包内置运行环境、浏览器、语音和语义模型。

## 快速开始

支持 **Windows 10 / 11 x64**，使用 CPU 即可运行。

**[下载 EchoSign v1.5 便携版](https://github.com/ys317/EchoSign/releases/download/v1.5/EchoSign-v1.5-win64.zip)**，或在 [Releases](https://github.com/ys317/EchoSign/releases/latest) 查看最新版本。

1. **解压并打开**：完整解压 `EchoSign-v1.5-win64.zip`，双击其中的 `EchoSign.exe`。请保留同目录下的 `_internal/` 和 `models/`。
2. **按需登录**：需要签到辅助时，填写本人学号和密码，点击「登录 / 刷新」，在打开的浏览器中完成验证。仅需转写和提醒时，关闭「自动签到」即可跳过登录。
3. **播放课程**：填写直播网址，点击「打开」并在浏览器中开始播放课程声音，然后点击「启动监控」。实时转写、提示与签到码会显示在右侧。
4. **结束监控**：课程结束后点击「停止监控」。修改设置后可点击「保存」，下次继续使用。

无需安装 Python，也无需额外运行安装脚本。GitHub 自动提供的 `Source code` 压缩包用于源码开发，不包含可直接运行的 exe。

## 常用设置

| 设置页 | 可以设置什么 |
| --- | --- |
| 课堂 | 课程网址、本人学号和密码、登录操作，以及是否启用自动签到。 |
| 识别 | 每行一个关键词，支持 `re:` 正则；可开启本地语义辅助识别。 |
| 通知 | 企业微信 Webhook 可留空；需要签到时请核对并填写本人真实经纬度。 |

点击「保存」或按 `Ctrl+S` 保存设置。监控期间修改识别、通知等设置后，需要停止并重新启动监控才能生效。软件使用填写的位置，不会自动检测当前位置。

更多说明见[使用指南](docs/usage.md)。

## 升级

关闭旧版，将新版解压到新目录。需要保留设置与登录态时，把旧目录中的以下内容复制到新目录：

- `config.yaml`：个人设置。
- `secrets_local.json`：账号和密码。
- `session_local.json`、`browser_profile/`：登录会话。

保留新版的 exe、`_internal/` 和 `models/`，打开后检查设置；登录过期时重新点击「登录 / 刷新」。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 没有实时转写？ | 确认课程正在播放，且从当前默认扬声器或耳机输出声音。切换输出设备后重启监控。 |
| 无法启动，或提示浏览器、模型缺失？ | 重新完整解压 Windows ZIP；不要在压缩包内运行，也不要只复制 exe。 |
| 未收到企业微信通知？ | 核对完整 Webhook 地址，点击「测试推送」。未填写地址时只在本机显示提醒。 |
| 登录过期或签到结果未知？ | 重新登录，并在「上课啦」页面核对最终结果。平台流程变化可能影响辅助功能。 |
| 无法保存设置？ | 将软件放在当前用户可写的目录，例如 `D:\Apps\EchoSign`。 |
| 支持其他学校或平台吗？ | 本地转写和规则提醒可以独立使用；登录与签到流程目前仅针对杭电「上课啦」适配。 |

## 开发与贡献

项目使用 Python，桌面界面基于 CustomTkinter。源码运行、命令行用法和构建说明见[开发指南](docs/development.md)。

```text
echosign/  应用入口、界面、音频、识别规则与签到
tests/     自动化测试和音频样本
tools/     构建、发布和资源维护
assets/    图标、界面截图与第三方许可证
docs/      使用指南、开发说明与第三方声明
```
