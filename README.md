面向杭电(杭州电子科技大学)「上课啦」的 Windows 课堂辅助工具。将课堂声音实时转为文字，识别签到提示与四位口播签到码，并提供可选的企业微信通知和浏览器签到辅助。

[下载 Windows 版](https://github.com/ys317/EchoSign/releases/latest) · [快速开始](#快速开始) · [使用指南](docs/usage.md) · [问题反馈](https://github.com/ys317/EchoSign/issues)

## 功能特点

- **本地语音识别**：采集电脑播放的声音，在本机完成流式中文转写，无需调用云端语音服务。
- **后台直播音频与预约**：自动读取杭电今明直播课程，当前课选择后即可直接接收声音，未来课可预约到点自动启动，无需复制每节课的网址或保持网页播放，可单独切换直播账号；默认使用单线程识别，降低持续 CPU 占用。
- **签到提示识别**：支持关键词、正则表达式、组合词和语义匹配，可按课堂习惯调整规则。
- **口播签到码提取**：识别四位数字及「一二三四」「幺二三四」等中文读法，满足确认条件时可在整句结束前提码，支持一键复制。
- **可选通知与辅助**：支持企业微信机器人提醒，以及「上课啦」的登录与签到操作；启动监控时提前打开签到页，缩短确认码后的等待。
- **深浅主题**：实时转写与活动记录分区显示，主题切换后自动记住选择。
- **解压即用**：Windows 发行包内置运行环境、浏览器、语音和语义模型。

## 快速开始

支持 **Windows 10 / 11 x64**，使用 CPU 即可运行。

**[下载 Windows 便携版](https://github.com/ys317/EchoSign/releases/latest)**。当前源码 v1.9 的变化见[更新说明](docs/releases/v1.9.md)。

1. **解压并打开**：完整解压 Windows ZIP，双击其中的 `HDUSign.exe`。请保留同目录下的 `_internal/` 和 `models/`。
2. **输入账号密码**：从侧栏账号菜单进入设置，填写本人学号和密码，点击「登录并读取课程」。软件自动填写登录表单，若平台要求验证码，在浏览器中完成即可；登录后自动列出今明直播课。
3. **一键预约或监控**：选择课程，底部同一个按钮会按开课时间显示「预约直播」或「开始监控」。预约后保持软件运行，到点自动开始。无需复制网址、选择音频模式或另行保存。
4. **结束或取消**：点击「停止监控」结束；预约等待期间点击「取消预约」。签到、通知和声音来源等选项统一放在「设置」。

无需安装 Python，也无需额外运行安装脚本。GitHub 自动提供的 `Source code` 压缩包用于源码开发，不包含可直接运行的 exe。

## 常用设置

| 设置页 | 可以设置什么 |
| --- | --- |
| 直播 | 账号密码、课程选择、随开课时间切换的操作按钮、监控状态；活动记录默认折叠。 |
| 设置 | 声音来源、手动网址、单独登录直播账号、自动签到与位置、识别关键词、语义辅助、企业微信通知。 |

登录、监控和预约时会自动保存；单独修改设置可点击「保存」或按 `Ctrl+S`。监控期间修改识别、通知等设置后，需要停止并重新启动监控才能生效。在「设置」页点击「获取当前位置」，可通过 Windows 定位填入经纬度；定位不可用时可手动填写。初始默认值为纬度 `30.314732`、经度 `120.343727`，使用前请核对本人实际位置。

更多说明见[使用指南](docs/usage.md)。

## 升级

关闭旧版，将新版解压到新目录。需要保留设置与登录态时，把旧目录中的以下内容复制到新目录：

- `config.yaml`：个人设置。
- `secrets_local.json`：账号和密码。
- `session_local.json`、`browser_profile/`：登录会话。
- `live_session.json`、`live_profile/`：使用过后台音频时的直播登录会话。

保留新版的 exe、`_internal/` 和 `models/`，打开后检查设置；直播登录过期时点击「登录并读取课程」，签到登录可在设置中刷新。v1.9 的签到会话按首页账号分别保存，首次使用可能需要重新验证。旧配置如仍使用 4 线程，可将 `asr.num_threads` 改为 `1` 并重启应用。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 没有实时转写？ | 先登录并选择正在直播的课程。电脑声音模式需从当前默认扬声器或耳机播放课程。 |
| 网页播放卡顿、占用高？ | 尝试后台音频，并关闭播放网页。目前支持杭电 HTTP(S)-FLV 直播，其他格式可继续使用电脑声音模式。 |
| 无法启动，或提示浏览器、模型缺失？ | 重新完整解压 Windows ZIP；不要在压缩包内运行，也不要只复制 exe。 |
| 未收到企业微信通知？ | 核对完整 Webhook 地址，点击「测试推送」。未填写地址时只在本机显示提醒。 |
| 登录过期或签到结果未知？ | 重新登录，并在「上课啦」页面核对最终结果。平台流程变化可能影响辅助功能。 |
| 无法保存设置？ | 将软件放在当前用户可写的目录，例如 `D:\Apps\HDUSign`。 |
| 支持其他学校或平台吗？ | 本地转写和规则提醒可以独立使用；登录与签到流程目前仅针对杭电「上课啦」适配。 |

## 开发与贡献

项目使用 Python，桌面界面基于 PySide6 / Qt Quick，使用增量数据模型和按需创建的活动列表。源码运行、命令行用法和构建说明见[开发指南](docs/development.md)。

```text
hdusign/  应用入口、界面、音频、识别规则与签到
tests/     自动化测试和音频样本
tools/     构建、发布和资源维护
assets/    图标、界面截图与第三方许可证
docs/      使用指南、开发说明与第三方声明
```

欢迎通过 [Issues](https://github.com/ys317/EchoSign/issues) 反馈问题、提出建议，或提交 Pull Request。反馈时请附上软件版本、Windows 版本和复现步骤，并遮盖账号、Webhook 与登录凭据。
