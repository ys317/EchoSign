# EchoSign

[![Release](https://img.shields.io/github/v/release/ys317/EchoSign)](https://github.com/ys317/EchoSign/releases/latest)
![Windows](https://img.shields.io/badge/Windows-10%20%2F%2011%20x64-0078D4)
[![MIT License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

面向**杭州电子科技大学「上课啦」**的 Windows 课堂辅助工具。将课堂声音实时转为文字，识别签到提示与四位口播签到码，并提供可选的企业微信通知和浏览器签到辅助。

[下载 Windows 版](https://github.com/ys317/EchoSign/releases/latest) · [快速开始](#快速开始) · [使用指南](docs/usage.md) · [问题反馈](https://github.com/ys317/EchoSign/issues)

## 功能特点

- **本地语音识别**：采集电脑播放的声音，在本机完成流式中文转写，无需调用云端语音服务。
- **后台直播音频**：自动读取杭电当前直播课程，选择后即可直接接收声音，无需复制每节课的网址或保持网页播放，可单独切换直播账号；默认使用单线程识别，降低持续 CPU 占用。
- **签到提示识别**：支持关键词、正则表达式、组合词和语义匹配，可按课堂习惯调整规则。
- **口播签到码提取**：识别四位数字及「一二三四」「幺二三四」等中文读法，满足确认条件时可在整句结束前提码，支持一键复制。
- **可选通知与辅助**：支持企业微信机器人提醒，以及「上课啦」的登录与签到操作；启动监控时提前打开签到页，缩短确认码后的等待。
- **深浅主题**：实时转写与活动记录分区显示，主题切换后自动记住选择。
- **解压即用**：Windows 发行包内置运行环境、浏览器、语音和语义模型。

## 快速开始

支持 **Windows 10 / 11 x64**，使用 CPU 即可运行。

**[下载 Windows 便携版](https://github.com/ys317/EchoSign/releases/latest)**。v1.7 的变化见[更新说明](docs/releases/v1.7.md)。

1. **解压并打开**：完整解压 Windows ZIP，双击其中的 `EchoSign.exe`。请保留同目录下的 `_internal/` 和 `models/`。
2. **按需登录**：需要签到辅助时，在「签到」页填写本人学号和密码，点击「登录 / 刷新」，在打开的浏览器中完成验证。仅需转写和提醒时，关闭「自动签到」即可跳过登录。
3. **选择声音来源**：在「课堂」页点击「登录直播」，完成验证后自动读取当前直播课程；从列表选择课程，再点「启动监控」，即可使用后台音频。之后打开软件会复用登录并刷新课程，也可点击「刷新课程」。若使用网页播放的声音，关闭「后台音频」即可。
4. **结束监控**：课程结束后点击「停止监控」。修改设置后可点击「保存」，下次继续使用。

无需安装 Python，也无需额外运行安装脚本。GitHub 自动提供的 `Source code` 压缩包用于源码开发，不包含可直接运行的 exe。

## 常用设置

| 设置页 | 可以设置什么 |
| --- | --- |
| 课堂 | 当前直播课程、直播登录与刷新、后台音频、自动签到；手动网址默认收起。 |
| 签到 | 本人学号和密码、签到登录、签到位置。 |
| 更多 | 识别关键词、语义辅助、企业微信通知与测试推送。 |

点击「保存」或按 `Ctrl+S` 保存设置。监控期间修改识别、通知等设置后，需要停止并重新启动监控才能生效。在「签到」页点击「获取当前位置」，可通过 Windows 定位填入经纬度；定位不可用时可手动填写。初始默认值为纬度 `30.314732`、经度 `120.343727`，使用前请核对本人实际位置。

更多说明见[使用指南](docs/usage.md)。

## 升级

关闭旧版，将新版解压到新目录。需要保留设置与登录态时，把旧目录中的以下内容复制到新目录：

- `config.yaml`：个人设置。
- `secrets_local.json`：账号和密码。
- `session_local.json`、`browser_profile/`：登录会话。
- `live_session.json`、`live_profile/`：使用过后台音频时的直播登录会话。

保留新版的 exe、`_internal/` 和 `models/`，打开后检查设置；签到登录过期时重新点击「登录 / 刷新」，直播登录过期时点击「登录直播」。旧配置如仍使用 4 线程，可将 `asr.num_threads` 改为 `1` 并重启应用。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 没有实时转写？ | 电脑声音模式需从当前默认扬声器或耳机播放课程。后台音频模式需确认课程正在直播，并已完成「登录直播」。 |
| 网页播放卡顿、占用高？ | 尝试后台音频，并关闭播放网页。目前支持杭电 HTTP(S)-FLV 直播，其他格式可继续使用电脑声音模式。 |
| 无法启动，或提示浏览器、模型缺失？ | 重新完整解压 Windows ZIP；不要在压缩包内运行，也不要只复制 exe。 |
| 未收到企业微信通知？ | 核对完整 Webhook 地址，点击「测试推送」。未填写地址时只在本机显示提醒。 |
| 登录过期或签到结果未知？ | 重新登录，并在「上课啦」页面核对最终结果。平台流程变化可能影响辅助功能。 |
| 无法保存设置？ | 将软件放在当前用户可写的目录，例如 `D:\Apps\EchoSign`。 |
| 支持其他学校或平台吗？ | 本地转写和规则提醒可以独立使用；登录与签到流程目前仅针对杭电「上课啦」适配。 |

## 开发与贡献

项目使用 Python，桌面界面基于 CustomTkinter。源码运行、命令行用法和构建说明见[开发指南](docs/development.md)。

```text
echosign/  应用入口、界面、音频、识别规则与签到
tests/     自动化测试和音频样本
tools/     构建、发布和资源维护
assets/    图标、界面截图与第三方许可证
docs/      使用指南、开发说明与第三方声明
```

欢迎通过 [Issues](https://github.com/ys317/EchoSign/issues) 反馈问题、提出建议，或提交 Pull Request。反馈时请附上软件版本、Windows 版本和复现步骤，并遮盖账号、Webhook 与登录凭据。
